Tour Card, iPhone app version

Files: index.html (the game), manifest.json + sw.js (make it installable and playable offline), icon-*.png (home screen icons), intro.mp4 + intro.webm + intro.jpg (the opening video and its still frame).

Put all of these files in the top level of your GitHub repository and turn on GitHub Pages (Settings > Pages > Deploy from a branch > main, / root).
On iPhone: open the Pages link in Safari, tap Share, then Add to Home Screen. It opens full screen like an app.

To update the game: replace index.html (and sw.js if a new one is provided) in your GitHub repository.
Your saves stay on your phone and carry over between versions.
The shared Hall of Fame and challenge boards only work in the Claude version; on GitHub, share challenge codes directly.
